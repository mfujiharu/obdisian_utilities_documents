# 本ノートの目的
[[Utilities/Documents/要件定義/要件定義|要件定義]]を実現するための全体方針を定める。設定値は[[Utilities/Documents/詳細設計/共通設定仕様|共通設定仕様]]、共通モジュールは[[Utilities/Documents/詳細設計/共通モジュール仕様|共通モジュール仕様]]を参照する。
# 開発方針
- 汎用モジュールと個別タスクスクリプトを分離する。
- ローカルで可能な処理はPythonで行い、AI問い合わせを最小限にする。
- タスクスクリプトは固有の判定と処理順だけを持つ。
- 仕様書と実装を同時に保守する。
# 実行方式
`main.py`をCLIエントリーポイントとする。
```bash
python main.py --task <task_name> --date 2026-07-30 --mode dry_run
python main.py --task <task_name> --date 2026-07-30 --mode execute
```
## 実行モード
- `dry_run`：対象抽出、AI問い合わせ、キャッシュ、変更予定生成まで行うが、書き込み・移動・削除・スナップショット取得は行わない。
- `execute`：対象と競合状態を再評価し、スナップショット取得後に書き込む。
`dry_run`は予測であり、後続`execute`の結果を固定しない。
## 対象日
- `arg`：`--date`必須
- `env`：指定環境変数必須
- `auto`：設定タイムゾーンの現在日
不足・不正時は暗黙フォールバックせず、開始前に中断する。

# AI使用可否
- `ai_check: false`：対象外判定に必要な最小限の管理ノート確認を除き処理しない。
- `ai_check: true`かつ`use_ai: false`：ローカル処理のみ。
- `ai_check: true`かつ`use_ai: true`：ローカル優先、必要時だけAI。

# パスの内部表現
- モジュール間：Vault相対POSIXパス
- ファイルI/O境界：OS絶対パスへ変換
- Wikilink：Vault相対パスから`.md`を除去
- 比較前：Unicode NFCへ正規化
- 正本表記：大文字小文字を区別
`Contracts/`だけを正規表記とする。
# 競合検出
読み込み時に`updated`、サイズ、`mtime_ns`、内容SHA-256を記録する。書き込み直前に1項目でも変化していれば競合として書き込まない。自動マージしない。
# 複数ファイル更新
1つの転記を1処理単位とし、全対象の競合確認、スナップショット、先行書き込み、再読込検証、後続書き込み、再読込検証の順で行う。
途中失敗時は安全に復元できる場合だけ処理単位全体を復元する。復元前競合または復元失敗では自動復元せず停止する。
# バッチ処理の継続単位
- 設定・必須引数ERROR：全体中断
- 管理ノートERROR：当該プロジェクトをスキップ
- 作業フォルダ候補0件・複数件：当該フォルダをスキップ
- 個別ノートERROR：当該ノートをスキップ
- 競合：当該処理単位を中止
- 書き込み後検証失敗：復元後、当該プロジェクトを中断
- 復元失敗：タスク全体を即時中断
# CLI終了コード
- `0`：正常終了。WARNING・正常スキップのみを含む
- `1`：設定・引数等による全体失敗
- `2`：一部対象の失敗
- `3`：競合更新
- `4`：AI/API失敗
- `5`：書き込み後検証または復元失敗
複数発生時は`5 > 1 > 4 > 3 > 2 > 0`の順で返す。
# Markdown処理
- Frontmatterの要素・順番を壊さない。
- 変更ブロック以外を一括整形しない。
- 見出しH1〜H6の直前・直後に空行を入れない。

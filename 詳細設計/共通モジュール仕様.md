# 共通結果
全モジュールは基本設計の状態コードと結果構造を使用する。
# パス
公開インターフェースはVault相対POSIXパスを受け渡す。OS絶対パスを外部へ返さない。
# エラー伝播
- WARNINGと正常スキップは継続する。
- `ambiguous`は自動選択せず対象をスキップする。
- `conflict`は書き込まない。
- `restore_error`はタスク全体へ伝播する。
# 結果集約
`main.py`は全結果を集約し、基本設計のCLI終了コードを決定する。

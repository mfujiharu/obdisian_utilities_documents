# 本ノートの目的
各タスクから共通利用するモジュール群の入口となる索引である。設定値は[[Utilities/Documents/詳細設計/共通設定仕様|共通設定仕様]]を参照し、個別機能の詳細は`モジュール/`配下の仕様書を正とする。
# モジュール設計原則
- タスクスクリプトはタスク固有の判定と処理順序だけを持つ。
- 共通処理をタスクスクリプトへ重複実装しない。
- `project_type`固有処理は`modules/project_types/`へ配置する。
- 依存方向は、タスクスクリプト→project_type別モジュール→共通モジュールを基本とする。
- 共通モジュールからタスクスクリプトを参照しない。
- ファイル書き込みは競合検出とスナップショット規定を経由する。

# 共通エラー方針
- ERROR：安全な処理継続ができない。仕様で定めたノート、プロジェクト、タスク単位で中断する。
- WARNING：対象をスキップするか、結果に影響しない範囲で継続する。
- INFO：既定値適用、条件不一致、正常なスキップ等を記録する。
# ログ共通項目
少なくとも時刻、レベル、タスク名、プロジェクト名、対象パス、操作、結果、理由を記録する。

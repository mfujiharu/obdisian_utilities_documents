# 本ノートの目的
全システム共通の設定ファイルと設定値の意味を定める。設定の読み込み・マージ処理は[[Utilities/Documents/詳細設計/モジュール/設定読み込み・実行コンテキスト|設定読み込み・実行コンテキスト]]を参照する。
# 設定ファイルの配置
```text
Utilities/
└─ config/
   ├─ .env
   ├─ config.yaml
   ├─ project_types/
   │  └─ プロジェクトタイプ名.yaml
   ├─ tasks/
   │  └─ 個別タスク名.yaml
   └─ schemas/
      ├─ common_frontmatter.yaml
      └─ project_types/
         └─ プロジェクトタイプ名_frontmatter.yaml
```
## `.env`
APIキー、トークン等の秘密情報だけを保存する。
```dotenv
ANTIGRAVITY_API_KEY=
GEMINI_API_KEY=
```
`.env`をログ、スナップショット、Git、OneDrive等の同期対象へ含めない。

# 設定の3層構造
1. `config/config.yaml`：全システム共通
2. `config/project_types/*.yaml`：`project_type`別
3. `config/tasks/*.yaml`：タスク別
後に読み込んだ層を優先する。複数プロジェクトを横断するタスクでは、プロジェクト別設定以降のマージをプロジェクトごとにやり直す。
# マージ規則
- スカラー：後勝ちで置換する。
- 辞書：キー単位で再帰的にマージする。
- 配列：後勝ちで配列全体を置換し、自動結合しない。
- `null`：値として置換し、キー削除には使用しない。
型が層間で異なる場合は後勝ちで置換するが、WARNINGとしてキー、旧型、新型、設定元を記録する。
# 設定値の検証
YAML構文エラー、必須設定不足、許容値外、タイムゾーン不正はERRORとし、タスク開始前に中断する。別の値へ暗黙にフォールバックしない。
# 設定値の配置基準
- 全タスク共通：`config.yaml`
- 複数タスクで共通し、`project_type`に依存：`project_types/*.yaml`
- タスク固有：`tasks/*.yaml`
- 秘密情報：`.env`
- Frontmatter検証条件：初期実装はPython内。将来`schemas/`へ外部化する。

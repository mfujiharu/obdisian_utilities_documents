# マージ規則
辞書は再帰マージする。配列・スカラー・`null`は後勝ちで全置換する。型変更はWARNINGとして記録する。
# 検証
構文エラー、必須不足、許容値外、未知の終了コード・パス形式・正規化方式はERRORとし、開始前に中断する。
# 正式名称
契約関連フォルダは`Contracts/`とする。旧表記を自動修正しない。

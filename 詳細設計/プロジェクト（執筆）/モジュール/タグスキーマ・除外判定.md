# 対象モジュール
- `modules/project_types/writing.py`
# `get_tag_schema(category)`
## インターフェース
`get_tag_schema(category)`
## 手順
1. `category`を`小説`、`漫画原作`、`ゲームシナリオ`の許容値と照合する。
2. [[Utilities/Documents/詳細設計/執筆タスク/データ整理ルール（執筆）#3. 作業ノート（`type: 作業ノート`）のタグ構造|データ整理ルール（執筆）]]に定義されたタグ階層を返す。
3. 未定義または未実装の`category`はERRORとし、空の汎用スキーマへフォールバックしない。
## 戻り値
タグ名だけでなく、親子関係、複数許容の有無、必須・任意を呼び出し元が判定できる構造で返す。
# `is_excluded(path, operation)`
## インターフェース
`is_excluded(path, operation)`
`operation`は少なくとも`read`、`write`、`move`、`delete`を受け取る。
## 判定
- `Books/`：読み取り可、書き込み・移動・削除不可。
- `Contracts/`：読み取りを含めて本システムの処理対象外。
- `Chapters/完了/`：除外判定に使用しない。作業状態はFrontmatterの`status`だけで判断する。
- 共通除外フォルダ：[[Utilities/Documents/詳細設計/データ整理ルール#3. 除外フォルダ|データ整理ルール]]に従う。
## パス判定
Vault相対パスを正規化し、フォルダ名をパスセグメント単位で完全一致判定する。`Contracts_old/`等を`Contracts/`として扱わない。
## 戻り値
単純な真偽値だけでなく、以下を返す。
- 許可・拒否
- 操作種別
- 適用した規則
- 対象フォルダ
- 理由
# フォルダ名の統一
契約関連フォルダの正規名称は`Contracts/`とする。`Contracts/`は旧表記としても認識せず、存在した場合はフォルダ構成不整合としてWARNINGを記録する。自動移動・自動改名は行わない。

# 適用範囲
`project_type: 執筆`のプロジェクトへ適用する。
# フォルダ構造
```text
プロジェクトフォルダ/
├─ プロジェクト名.md
├─ index.md
├─ Temp/
├─ Settings/
├─ Chapters/
│  ├─ 全体構成.md
│  ├─ 作業フォルダ/
│  └─ 完了/
├─ Books/
└─ Contracts/
```
# 状態判定
`Chapters/完了/`はユーザー整理用であり、状態・検索・編集可否の判定に使用しない。作業状態は作業ノートのFrontmatterの`status`だけで判断する。
# 読み取り・転記
- 読み取り検索：タスクに応じて`status=True`、`False`、`None`
- 転記先検索：必ず`status=True`
# 作業ノート件数
作業フォルダ内で条件一致する作業ノートが0件ならWARNINGでスキップ、1件なら使用、2件以上なら`ambiguous`でスキップする。
# 除外フォルダ
- `Books/`：読み取り可、書き込み・移動・削除不可
- `Contracts/`：読み取りを含む全処理禁止
- `Contracts/`等の旧表記：WARNING。自動改名・移動しない
# 名前とパス
比較前にUnicode NFCへ正規化する。正本表記では大文字小文字を区別し、パスセグメント単位で完全一致する。
# 転記
転記は一度限りの一方向コピーとし、`#転記済`付きブロックを再転記しない。追加内容は新規未転記ブロックとして作成する。

# 役割
設定値と索引を担い、機能詳細は`モジュール/`配下を正とする。
# 設定
```yaml
writing:
  skip_tag: "転記済"
  settings_fallback_node: "保留"
  fallback_section: "メモ"
```
値は空でない文字列とし、先頭の`#`を含めない。

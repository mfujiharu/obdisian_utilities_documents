# タスク名
`cull_settings`
# 設定
```yaml
cull_settings:
  use_ai: true
  max_lookback_days: 30
  review_required: false
```
# 対象
`project_type: 執筆`、`status: true`、`ai_check: true`のプロジェクト内で、`status: true`の作業ノートを対象とする。
# 処理
1. 作業ノートのタグなし行へ一時IDを付与する。
2. プロジェクト管理ノートを文脈としてAIへ1作業ノート1リクエストで問い合わせる。
3. JSONの`unnecessary_ids`を検証する。
4. 転記用ツリーと削除後ツリーをメモリ上で生成する。
5. 直近の既存デイリーノートを検索する。
6. 転記元・転記先の競合確認とスナップショットを行う。
7. デイリーノートへ追記し、再読込検証する。
8. 成功後に作業ノートから対象を削除し、再読込検証する。
人手確認フェーズは設けない。`dry_run`では変更予定だけを出力する。
# 異常時
AI通信・JSON・ID・一意性エラーでは変更しない。後続削除失敗時は、安全なら処理単位全体を復元する。
# 移動処理ID
同一移動の二重追記を防ぐため`cull_transfer_id`を使用する。
## 算出材料
- Vault相対転記元パス
- AI判定時の`updated`
- 正規化済み不要ID一覧
- 転記対象ブロックの正規化本文
## 形式
```markdown
<!-- cull_transfer_id: sha256:... -->
```
転記ブロック直前へ記録する。同一IDが1件あれば重複追記しない。複数あれば状態不整合としてERRORとする。このIDは差分同期に使用しない。

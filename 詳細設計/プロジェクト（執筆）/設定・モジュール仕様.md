# 本ノートの目的
[[Utilities/Documents/基本設計/基本設計#詳細設計ノート一覧|基本設計]]に基づき、`project_type: 執筆`に固有の設定値と`modules/project_types/writing.py`の責務を定める。
個別機能の詳細は`モジュール/`配下の仕様書を正とする。
# 設定ファイル（`config/project_types/writing.yaml`）
```yaml
writing:
  skip_tag: "転記済"                 # 転記処理スキップ判定に用いるタグ名。#は含めない
  settings_fallback_node: "保留"     # 設定ノート追記時のフォールバックノード名。#は含めない
  fallback_section: "メモ"           # 作業ノート追記時のフォールバックセクション名。#は含めない
```
## 設定値の検証
- 各値は空でない文字列でなければならない。
- 値には先頭の`#`を含めない。タグとして使用する際にモジュール側で`#`を付与する。
- 設定不足または型不正の場合はERRORとし、当該プロジェクトの処理を開始しない。
# モジュール（`modules/project_types/writing.py`）
`project_type: 執筆`のフォルダ配置、タグ構造、ノート種別に依存する処理を担当する。
Markdown構文解析、Frontmatter検証、Wikilink生成、競合検出、スナップショット取得は共通モジュールを利用し、本モジュールへ重複実装しない。

# 共通の戻り値・エラー方針
検索・追記機能は、少なくとも処理の成否、対象パス、WARNING一覧、ERROR一覧、スキップ理由を呼び出し元が判定できる形で返す。
- 候補0件：仕様で別段の定めがない限り、対象なしとして`None`または空配列を返す。
- 候補1件：該当パスまたは処理結果を返す。
- 候補2件以上：自動選択せず、一意性エラーまたはスキップとして扱う。
- 1件の異常によって、ほかの正常なノートや作業フォルダの処理を不必要に停止しない。
# 転記の一方向性
転記は一度限りの一方向コピーとする。`#skip_tag`が付いたブロックは、後から編集されても再転記、差分同期、置換を行わない。追加で反映する内容は、ユーザーが新しい未転記ブロックとして作成する。転記シグネチャは持たせない。

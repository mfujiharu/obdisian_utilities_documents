# 共通判定
返却状態、ログ、CLI終了コード、差分、スナップショット、再実行結果を確認する。
# 1. プロジェクト探索
正常、`ai_check: false`、管理ノートなし・複数・不正。
# 2. 作業ノート検出
`status=True`・`False`・`None`、完了フォルダとstatusの不一致、候補0・1・複数。
# 3. 転記先候補
候補0・1・複数、補助タグ、`#転記済`。
# 4. 設定ノート追記
必須ツリーあり、不足階層作成、同名ツリー複数。
# 5. 作業ノート追記
同名セクション0・1・複数、フォールバック0・1・複数、複数追記単位、タグなし、複数タグ。
# 6. ファイル安全性
`updated`・サイズ・mtime・ハッシュ変更、同一秒内変更、転記元更新失敗、復元成功、復元前競合、復元失敗。
# 7. `cull_settings`
正常JSON、空、不正JSON、不正ID、重複ID、タイムアウト、`cull_transfer_id`による重複防止と複数IDエラー。
# 8. キャッシュ
ヒット、各入力変更によるミス、エラー非保存。
# 9. 結合成果物
非分割、分割、複数part、単一原本超過、旧part、シグネチャ一致。
# 10. CLI・バッチ
WARNINGのみ`0`、一部失敗`2`、競合`3`、AI失敗`4`、復元失敗`5`、重大度順。
# 受入条件
テスト用Vaultで全必須ケースが再現でき、差分が仕様で許可された範囲だけであること。

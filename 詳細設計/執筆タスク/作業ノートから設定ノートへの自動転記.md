# タスクの概要
本タスクは`project_type: 執筆`用のタスクである。
`Chapters/`以下の作業ノートを走査し、キャラクターや世界設定など設定に関する記述を検出して、該当する`Settings/`以下の設定ノートへコピー・追記する。（作業ノート内の該当箇所自体は削除せず、転記済みである旨のみを記録する）
# 前提条件
スクリプトの実行環境、前提条件、基本ルールは、[[Utilities/Documents/基本設計/基本設計|基本設計]]を参照のこと。
# タスク名
本個別タスクのタスク名は「**organize_settings**」とする。
# 本タスク用設定ファイル
本タスク用の設定ファイルには、以下を記述する。
（ファイルパス：`config/tasks/organize_settings.yaml`）
```
organize_settings:
  use_ai: true              # プロジェクト管理ノートからの設定ノート用タグ抽出等でAIを使用する
```
`skip_tag`・`settings_fallback_node`は、`project_type`（本タスクでは`執筆`）ごとの規約値のため、[[Utilities/Documents/詳細設計/執筆タスク/プロジェクトタイプ（執筆）設定・モジュール仕様|プロジェクトタイプ（執筆）設定・モジュール仕様]]を参照する。
# 整理・抽出手順
## 1. 設定ファイルの読み込み
## 2. 対象プロジェクトの抽出
[[Utilities/Documents/詳細設計/共通設定・モジュール仕様#プロジェクト探索モジュール（`project_discovery.py`）|プロジェクト探索モジュール]]の`find_projects()`を用い、以下を満たすプロジェクトを検出する。
- `project_type: 執筆`
- `status: true`
- `ai_check: true`

同時に **プロジェクト名（=`project_name`）** を取得する。
## 3. 対象作業ノートの検出
[[Utilities/Documents/詳細設計/執筆タスク/プロジェクトタイプ（執筆）設定・モジュール仕様|プロジェクトタイプ（執筆）設定・モジュール仕様]]の「作業ノートの検出」処理を用いて、
- プロジェクト名
- （ノート名は空欄とする）
- `status: true`

を引数として与え、タスク処理を行う作業ノートの一覧を得る。
以降の処理は、対象となる各作業ノートに対して行う。
## 4. 作業ノート内の全ノードを走査する
作業ノートをMarkdown構造で解析し、`#プロジェクト名`（例: `#今世は悪女`）配下の**全ノードを、深さを問わず**走査する。

※[[Utilities/Documents/詳細設計/データ整理ルール（執筆）#3. 作業ノート（`type: 作業ノート`)のタグ構造|データ整理ルール（執筆）]]の通り、作業ノートでは`#プロジェクト名`の直下の子は`#作業フォルダ名`ひとつのみであり、設定に関するタグ（キャラ名等）は`#メモ`や`#プロット`配下など、より深い階層に散在する。そのため[[Utilities/Documents/詳細設計/執筆タスク/デイリーノートから作業・設定ノートへの自動転記|デイリーノートから作業・設定ノートへの自動転記]]（直下の子ノードのみを走査する）とは異なり、本タスクでは配下の全ノードを走査対象とする。
## 5. 各ノードの判定
走査した各ノードについて、以下を順に判定する。
1. 転記処理スキップ判定
2. ノード内のタグを元に、[[Utilities/Documents/詳細設計/執筆タスク/プロジェクトタイプ（執筆）設定・モジュール仕様#設定ノートの検出|「設定ノートの検出」]]で所在を特定する

1に当てはまった場合は処理をスキップする。
2で`None`が返ってきた場合も処理をスキップする。（設定ノート宛ではないノードは、作業ノート側に変更を加えずそのまま残す）
2で使用したノード内のタグ（`#子ノードのタグ`）は、後段の「設定ノートへ追記する」処理でもそのまま用いる。
## テキストをコピーする
合致したノードのブロック（**子や孫ノードも含めた、配下にある全ての箇条書き**）を、階層構造を維持したまま一括コピーする。
## 特定したノートに追記する
転記先の設定ノートへの追記処理は、[[Utilities/Documents/詳細設計/執筆タスク/プロジェクトタイプ（執筆）設定・モジュール仕様#設定ノートへ追記する|プロジェクトタイプ（執筆）設定・モジュール仕様]]の「設定ノートへ追記する」処理に従う。
## 重複転記防止処理（作業ノート側の更新）
二重処理防止および参照追跡のため、作業ノート側の該当ノードに`#skip_tag`を記載する。
- フォーマット: `#子ノードのタグ` ▶  [[転記先ノートへのフルパス]] へ `#skip_tag`

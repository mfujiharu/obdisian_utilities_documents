# 本ノートの目的
[[Utilities/Documents/基本設計/基本設計#詳細設計ノート一覧|基本設計]]に基づき、`project_type: 執筆`に固有の設定値・モジュール関数の詳細をまとめる。
# 設定ファイル（`config/project_types/writing.yaml`）
```
writing:
  skip_tag: "転記済"                 # 転記処理スキップ判定に用いるタグ
  settings_fallback_node: "保留"     # 設定ノート追記時のフォールバックノード名
  fallback_section: "メモ"           # 作業ノート追記時、該当セクションがない場合の既定セクション名
```
# モジュール（`modules/project_types/writing.py`) 
`project_type: 執筆`のプロジェクトに固有の処理を担う。
最低限、以下の機能を持つこと。
## プロジェクト管理ノートから、設定ノート用のタグを取得する
プロジェクト管理ノートの「キャラクター一覧」「設定項目一覧」の項からタグを取得する。
[[Utilities/Documents/詳細設計/共通設定・モジュール仕様#2 ローカル処理優先・AIはフォールバック|AI問い合わせモジュールの運用ルール]]に従い、まず定められた軽量書式（[[Utilities/Documents/詳細設計/データ整理ルール（執筆）#4. `Settings/`|データ整理ルール（執筆）]]参照）に沿ったローカル解析を試み、書式に従っていない場合や抽出結果が空になる場合にのみAIにフォールバックする。
## 転記処理スキップ判定
子ノードのテキストを受け取り、処理スキップ条件に当てはまるかを判定する。
- テキストに`#skip_tag`が含まれる場合
- （`#skip_tag`を除いて）タグが0個、あるいは2個以上含まれる場合
## 設定ノートの検出
**プロジェクト名**、**ノート名（空欄を認める。`#`を含むタグ文字列。例：`#アナスタシア`）** を引数として受け取り、`Settings/`以下から該当する設定ノートを探す。
- `Settings/`以下に存在する
- プロジェクト管理ノートから取得した設定ノート用のタグ名と一致する

ノート名が上の条件を満たした場合は、設定ノートのフルパスを返す。
引数のノート名が空欄だった場合は、該当する設定ノートのフルパスを配列で返す。
どちらにも該当しなければ`None`を返す。

- 例1： `転生女帝` + `#アナスタシア`　→ `Settings/アナスタシア.md`
- 例2： `転生女帝` + `#世界設定`　→ `Settings/世界設定.md`
## 作業ノートの検出
**プロジェクト名**、**ノート名（空欄を認める。`#`を含むタグ文字列。例：`#1話`）**、**`status`** の値（`true`か`false`）を引数として受け取り、`Chapters/`以下（サブフォルダ含む）から該当する作業ノートを探す。
### α: 全体構成ノート
- ノート名が「全体構成」である
### β: 作業フォルダの作業ノート（`Chapters/作業フォルダ/作業ノート.md`）
- `Chapters/`以下のサブフォルダの中にある（※フォルダの階層は問わない）
- フォルダ内に、他に作業ノートが存在しない
- 作業ノートの`status`が引数の値と合致する

引数のノート名がα、βの**いずれか一方**を満たした場合は、作業ノートのフルパスを返す。
引数のノート名が空欄だった場合は、該当する作業ノートのフルパスを配列で返す。
どちらにも該当しなければ`None`を返す。

- 例1： `今世は悪女` > `全体構成` ➔ `Chapters/全体構成.md`
- 例2： `今世は悪女` > `5話` ➔ `Chapters/5話/5話作業ノート.md`
- 例3： `今世は悪女` > `1話` ➔ `Chapters/完了/1話/1話作業ノート.md`
## 設定ノートへ追記する
1. 転記先の設定ノートを開く。
2. `#プロジェクト名` > `#子ノードのタグ` > `#settings_fallback_node`のノードを含む箇条書きツリーを検索する。
3. ノードが欠けている場合は、新規に不足ノードを追記する。
	1. `#プロジェクト名` > `#子ノードのタグ`のツリーがある場合： 下に`#settings_fallback_node`のノードを追記する。
	2. `#プロジェクト名`のツリーがある場合： 下に `#子ノードのタグ` > `#settings_fallback_node`のノードを追記する。
	3.  `#プロジェクト名`のツリーがない場合： 
		1. 設定ノートの末尾に、新規に`#プロジェクト名`の箇条書きツリーを追記する。
		2. その下に、 `#子ノードのタグ` > `#settings_fallback_node`のノードを追記する。
4. コピーしたブロックから、`#子ノードのタグ`を含むノードを削除する。
5. 加工したブロックを、`#settings_fallback_node`の子ノードとして、インデントレベルを揃えて追記する。

※ここでの`#子ノードのタグ`には、「設定ノートの検出」呼び出し時に渡した（あるいはそれによって特定された）ノート名タグをそのまま用いること。
## 作業ノートへ追記する
1. 転記先の作業ノートを開く。
2. `#プロジェクト名` > `#子ノードのタグ`を含む箇条書きツリーを探す。
3. `#子ノードのタグ`の子ノード以下から、







4. コピーしたブロックから、`#子ノードのタグ`を含むブロックを削除する。
5. 該当するタグセクション（例: `#メモ` や `#1話`）の**一番下の子ブロック（配下の末尾）** に改行を入れて、インデントのレベルを調整（該当セクションの子要素として揃える）しながら追記する。
6. 該当するタグセクションが複数ある場合は、最後に出現したタグセクションの末尾に追記する。
7. 該当するタグセクションがない場合は、`fallback_section`で指定されたセクション（既定値：`#メモ`）の末尾へ同様に追記する。
## `get_tag_schema(category)`
プロジェクト管理ノートの`category`（`小説`/`漫画原作`/`ゲームシナリオ`）に応じたタグ階層定義を返す（[[Utilities/Documents/詳細設計/データ整理ルール（執筆）|データ整理ルール（執筆）]]の「作業ノートのタグ構造」参照）。
## `is_excluded(path)`
`Chapters/完了/`・`Books/`・`Contract/`など、執筆プロジェクト固有の除外フォルダに該当するかどうか、および読み取りのみ可か編集も不可かを判定する（[[Utilities/Documents/詳細設計/データ整理ルール（執筆）#8. 除外フォルダ|データ整理ルール（執筆）]]参照）。

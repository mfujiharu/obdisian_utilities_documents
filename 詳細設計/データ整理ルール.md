# About This Note
本ノートは、Obsidianにおけるフォルダ階層・タグ管理の具体的な定義（詳細設計）である。本システムによるファイル操作の絶対制約、`ai_check`、削除・移動の扱いは[[Utilities/Documents/要件定義/要件定義|要件定義]]を参照。
# フォルダ分類ルール・階層構造
Vault以下のフォルダは以下に分類され、整理・管理される。
## 1. プロジェクトフォルダ
プロジェクトフォルダとは、以下の条件を満たすフォルダを指す。
- Vault直下にある
- 除外フォルダに該当しない
- **プロジェクト管理ノート**を持つ
### 1. プロジェクト管理ノート
プロジェクト管理ノートは、以下の条件を満たすノートである。
- フォルダ直下にある
- フォルダと同名のノートである
- Frontmatterに`type: プロジェクト管理ノート`の記述がある
### 2. プロジェクト名
プロジェクト管理ノートの **`project_name` = プロジェクト名** となる。
### 3. プロジェクト別のデータ整理ルール
プロジェクトフォルダ内部のデータには、Frontmatterの`project_type` の値に応じた整理ルールが適用される。

- **`project_type: 執筆`** ➔ [[Utilities/Documents/詳細設計/データ整理ルール（執筆）|データ整理ルール（執筆）]] を参照
- **`project_type: デスク環境`** ➔ （※検討中）
## 2. デイリーノート
デイリーノートは、Vault直下の以下のフォルダにある。
- Vault/
	- DailyNote/

ファイル名は`YYYY-MM-DD.md`形式とする（例：`2026-07-30.md`）。
## 3. 除外フォルダ
以下のフォルダ以下のデータは、本システムによる読み取りは可能だが、作成・追記・更新・移動・削除は不可とする。
- Vault/
	- copilot/
	- Utilities/
	- Web Clipper/
	- スポット/
# Frontmatterパラメータ定義
全ノート種別に共通するフィールドの意味・許容値を以下に定める。 
個別ノート種別固有のフィールド（例：`episode`）は、各プロジェクトルールを参照。
## 1. 全ノート共通
| フィールド       | 意味        | 許容値・書式                                                                                                  | 必須/任意 |
| ----------- | --------- | ------------------------------------------------------------------------------------------------------- | ----- |
| title       | ノートのタイトル  | 自由文字列                                                                                                   | 必須    |
| type        | ノートの種別    | 共通： `プロジェクト管理ノート`/`デイリーノート`/`ルール`/`タスク`<br>プロジェクト固有の値は、`project_type`別ルール（[[#3. プロジェクト別のデータ整理ルール]])を参照。 | 必須    |
| description | ノートの説明    | 自由記述                                                                                                    | 任意    |
| created     | 作成日時     | ISO 8601形式（テンプレート：`YYYY-MM-DDTHH:mm:ssZ`）。`Z`はタイムゾーンオフセットを表す。ノート作成時に自動設定する | 必須 |
| updated     | 最終更新日時 | ISO 8601形式（テンプレート：`YYYY-MM-DDTHH:mm:ssZ`）。`Z`はタイムゾーンオフセットを表す。Obsidianによる編集時およびPythonによる書き込み時に自動更新する | 必須 |
| tags        | 内容に関連するタグ | 配列                                                                                                      | 任意    |
## プロジェクト管理ノート
| フィールド   | 意味                                           | 許容値・説明                                                                                                                                                                                                                                                                                                                                   | 必須/任意 |
| ------------ | ---------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------- |
| project_type | プロジェクトの種類                             | `執筆`/`デスク環境`                                                                                                                                                                                                                                                                                                                            | 必須      |
| project_name | プロジェクト名                                 | 自由記述                                                                                                                                                                                                                                                                                                                                       | 必須      |
| category     | プロジェクト内の区分                           | `project_type`別ルールを参照。                                                                                                                                                                                                                                                                                                                 | 必須      |
| status       | 進行中か否か                                   | `true`/`false`                                                                                                                                                                                                                                                                                                                                 | 必須      |
| ai_check     | 本システムの自動処理対象に含めるかを示すフラグ | `true`：個別タスクの仕様と安全規定の範囲で、読み取り・構造解析・AI入力・作成・追記・更新・結合成果物への収録を許可する。`false`：管理ノートのFrontmatterを確認して対象外と判定するために必要な最小限の処理を除き、自動処理対象から除外する。詳細は[[Utilities/Documents/要件定義/要件定義#AI自動処理許可フラグ（ai_check） \| 要件定義]]を参照 | 必須      |

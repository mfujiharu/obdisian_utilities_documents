# 対象モジュール
- `artifact_builder.py`
# インターフェース
`combine_notes(note_paths, output_path, frontmatter, build_options)`
# 共通Frontmatter
- `artifact_type`
- `artifact_role`：`single` / `index` / `part`
- `artifact_schema_version`
- `source_signature_version`
- `source_signature`
- `generator_version`
- `generated_at`
- `source_count`
# シグネチャ
成果物種別、役割、構造バージョン、生成ロジック、選定・変換・並び順・分割条件、各原本の相対パスと`updated`、テンプレートハッシュを正規化し、SHA-256で算出する。`generated_at`は含めない。
# 出典境界
設定で有効化された場合、原本ごとに相対パス、`type`、`updated`を含む境界コメントとWikilink見出しを付与する。
# 分割条件
変換後のUTF-8バイト数または原本数が上限を超えた場合に分割する。原本ノートの途中分割は禁止し、単一原本だけで上限を超える場合はERRORとする。
# 分割方式
タスク側がグループ定義を渡す。グループ内は`sort_policy`の順序を保ち、次の原本を追加すると上限超過する時点で次partを開始する。
# ファイル名
`{stem}_{group_order:02d}_{group_label}_{part_number:03d}.md`
# indexとpart
- 非分割：`artifact_role: single`
- 分割親：`artifact_role: index`
- 分割子：`artifact_role: part`
各partは収録原本だけを材料とする個別シグネチャを持つ。indexはpartのパスとシグネチャから全体シグネチャを作る。
# マニフェスト
成果物ごとに`{stem}.manifest.json`を1ファイル生成する。分割時もpartごとの個別マニフェストは作らない。
# 原子的更新
分割計画、一時ファイル、シグネチャ、マニフェストを先に生成・検証し、スナップショット取得後に正式ファイルへ置換する。途中失敗時は既存成果物を変更しない。
# 過去の不要part
自動削除しない。現行マニフェストに記載されたpartだけを有効とし、不要候補をWARNINGへ記録する。

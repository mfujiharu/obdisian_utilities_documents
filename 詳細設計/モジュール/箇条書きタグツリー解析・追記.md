# 対象モジュール
- `markdown_tag_tree.py`
# 必須機能
- 指定タグを起点に子孫ブロックを構造保持して抽出する。
- 指定ツリー配下を深さを問わず列挙する。
- 指定セクション配下の末尾へブロックを追記する。
- 指定タグを含むノードを配下ごと削除する。
- 指定タグの存在を完全一致で判定する。
- 転記済みマーキングを付与する。
# タグ一致
前方一致を禁止し、`#1話`と`#1話目`を区別する。
# 転記先候補
単純なタグ数ではなく、設定ノートまたは作業ノートとして解決できたフルパスの件数で判定する。
- 0件：スキップ
- 1件：転記
- 2件以上：一意に確定できないためスキップ
タグ順や更新日時で自動選択しない。
# 転記済みブロック
`#skip_tag`を含むブロックは再転記しない。転記後の編集を同期せず、追加内容は新しい未転記ブロックとして作成する。
# 書式
既存ノートのインデント形式を優先し、ノート内へ異なる形式を混在させない。

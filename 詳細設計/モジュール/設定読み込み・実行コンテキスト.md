# 対象
- `config_loader.py`
- `run_context.py`
# 設定読み込み
共通、project_type別、タスク別の順で読み込み、辞書は再帰マージ、その他は後勝ちで置換する。
# パス正規化
Vaultルートを基準に入力パスをVault相対POSIXパスへ変換し、Unicode NFCへ正規化する。
# 対象日
`arg`、`env`、`auto`のいずれかで解決する。不足・不正時は暗黙フォールバックしない。
# AI使用可否
`ai_check: false`は対象外、`use_ai: false`はローカルのみ、`use_ai: true`はローカル優先で必要時のみAIとする。
# 実行結果集約
共通結果を集約し、終了コードを決定する。
# 終了コード
`0`正常、`1`全体失敗、`2`一部失敗、`3`競合、`4`AI失敗、`5`書き込み・復元失敗。複数時は`5 > 1 > 4 > 3 > 2 > 0`。

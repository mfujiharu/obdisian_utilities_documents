# 対象モジュール
- `file_transaction.py`
- `snapshot.py`
# 読み取り状態
書き込み候補を読んだ時点で相対パス、Frontmatterの`updated`、ファイル最終更新時刻、サイズを保持する。
# 競合検出
書き込み直前に再取得し、読込時から`updated`が変化していれば競合として中止する。最新内容との自動マージは行わない。
# 処理単位
1つの転記ブロック等、論理的に一体の複数ファイル変更を1トランザクション相当として扱う。
# 更新手順
1. 全対象ファイルの競合確認
2. `execute`時だけ全ファイルのスナップショット取得
3. 転記先等の先行ファイルを書き込み
4. 再読込して内容と`updated`を検証
5. 転記元等の後続ファイルを書き込み
6. 再読込して検証
7. 全成功後に完了記録
# 途中失敗
復元対象がスナップショット後に第三者更新されていない場合だけ、処理単位全体を復元する。競合があれば自動復元せず、対象、段階、スナップショット場所をERRORへ記録する。
# スナップショット
`snapshots/YYYY-MM-DD/`配下へVault構造を保って保存する。`dry_run`では取得しない。保持期間超過分は自動削除する。
# 除外
`.venv`、`snapshots`、`logs`、`cache`、`.env`は同期・Git管理から除外する。

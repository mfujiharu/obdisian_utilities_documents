# 対象
- `file_transaction.py`
- `snapshot.py`
# 読み取り状態
```yaml
path: Vault/relative/path.md
updated: YYYY-MM-DDTHH:mm:ssZ
size: 12345
mtime_ns: 123456789
content_sha256: sha256:...
```
# 競合判定
書き込み直前に4項目を再取得し、1項目でも変化していれば`conflict`とする。同一秒内でも内容ハッシュで検出する。自動マージしない。
# 更新手順
1. 全対象の競合確認
2. `execute`時だけスナップショット取得
3. 先行ファイル書き込み
4. 再読込検証
5. 後続ファイル書き込み
6. 再読込検証
7. 全成功後に完了
# 復元
復元対象が、失敗処理が最後に生成した状態と一致する場合だけ自動復元する。第三者更新時は復元しない。復元失敗は`restore_error`とし、タスク全体を中断する。
# スナップショット
日付別フォルダへVault相対構造を保って保存する。`dry_run`では取得しない。

# ドキュメント群について
Obsidianノート自動処理システムの要件定義、基本設計、詳細設計を管理する。
# ディレクトリ構造
```text
README.md
基本設計/
└─ 基本設計.md
要件定義/
└─ 要件定義.md
詳細設計/
├─ Python実行環境・AIエージェント情報.md
├─ データ整理ルール.md
├─ 共通設定仕様.md
├─ 共通モジュール仕様.md
├─ 初期実装テスト仕様.md
├─ 仕様書リンク移行チェック.md
├─ モジュール/
│  ├─ AI問い合わせ・キャッシュ.md
│  ├─ Frontmatter検証.md
│  ├─ Markdown・Frontmatter入出力.md
│  ├─ ノート探索・Wikilink構築.md
│  ├─ ファイル安全管理.md
│  ├─ 箇条書きタグツリー解析・追記.md
│  ├─ 結合成果物生成.md
│  └─ 設定読み込み・実行コンテキスト.md
└─ プロジェクト（執筆）/
   ├─ データ整理ルール（執筆）.md
   ├─ プロジェクトタイプ（執筆）設定・モジュール仕様.md
   ├─ モジュール/
   │  ├─ タグスキーマ・除外判定.md
   │  ├─ 作業ノート追記.md

      ├─ デイリーノートから作業・設定ノートへの自動転記.md
      ├─ 作業ノートから設定ノートへの自動転記.md
```

# 正式名称
- 執筆プロジェクトの索引：`プロジェクトタイプ（執筆）設定・モジュール仕様.md`
- 契約関連フォルダ：`Contracts/`
- 旧パス・旧名称は新規記述へ使用しない。
# パス表現
仕様書のWikilinkおよびプログラム内部の識別子はVault相対POSIXパスを使用する。
